# Información

- Compilador: GCC
- Version: 13.2.0
- Version del compilador de C: C23


### Como usar hola.c

1) Abrir una terminal, sea el cmd, powershell, etc
2) Escribir en la terminal "cd C:/(Ruta al directorio donde se encuentra la carpeta con el archivo)"
3) Compilar hola.c y crear su ejecutable de la siguiente manera: "gcc hola.c -o hola.exe"
4) Ejecutar hola.exe en la terminal como "hola.exe" para verificar que funciona
5) Redireccionar hola.exe a output.txt: "hola.exe > output.txt"
6) Abrir output.txt para comprobar su contenido
